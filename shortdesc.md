# AI Factory Summary

AI Factory is a lightweight, pluggable AI pipeline system that captures signals from external sources like cron jobs, webhooks, email, Slack, and filesystem events. It routes these signals through a swarm of AI agents via four core stages: Inbound (sensors emit RawSignal objects), Adapt (channel-specific adapters normalize signals into Task objects), Orchestrate (the Orchestrator decomposes tasks, selects models, dispatches to agents, and aggregates results), and Outbound (responders deliver final outputs back to the source channel). The system is initialized by main.ts, which configures an LLM provider—preferring local oMLX models containing 'qwen' unless overridden in factory.config.json. Users can send signals via cron (enabled by default), webhooks, file watching, email IMAP polling, or Slack integrations. Development follows strict TypeScript conventions and includes linting, type-checking, and testing workflows to ensure reliability.
