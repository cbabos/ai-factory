# AI Factory Summary

AI Factory is a lightweight, pluggable AI pipeline system that captures signals from cron jobs, webhooks, email, Slack, and filesystem events. It can route work through either the adaptive orchestrator or the deterministic workflow engine with human-in-the-loop pauses, resumptions, and approvals. The workflow system now includes a visual editor, workflow runs, human task inboxes, task-scoped saved artifacts under `out/artifacts`, and a seeded requirements workflow that drafts markdown documents, extracts open questions, and presents clarification requests as questionnaire fields plus bulk answer fallback. The runtime is initialized by `main.ts`, prefers local oMLX models containing `qwen` unless overridden, persists state in SQLite, and serves the UI/API from the same factory process.
